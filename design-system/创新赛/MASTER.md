# 城更智算舱设计系统

## 产品原则

- 面向非专业甲方，一屏只处理一个主要任务。
- 用结果、依据和下一步代替技术参数、模型提示词和长篇说明。
- 苹果式信息克制与留白负责视觉层级，Material 3 负责表单、步骤、状态和错误反馈。
- 所有 AI 结论必须显示脱敏依据摘要、版本和人工复核项。

## 设计令牌

| 角色 | 值 | 用途 |
|---|---|---|
| 主色 | `#1F6048` | 主按钮、当前步骤、正向状态 |
| 深主色 | `#174936` | 悬停和高强调文字 |
| 信息色 | `#315F94` | 数据与隐私说明 |
| 提醒色 | `#9A6417` | 风险与人工复核 |
| 页面背景 | `#F5F6F7` | 应用背景 |
| 卡片 | `#FFFFFF` | 主要内容表面 |
| 正文 | `#17211D` | 标题与正文 |
| 次级文字 | `#68736D` | 说明和元数据 |
| 分隔线 | `#DFE5E1` | 卡片和表格边界 |

- 字体使用系统字体栈，不加载外部字体。
- 间距以 `4/8px` 为基准，主要层级使用 `12/16/20/24/28/32px`。
- 卡片圆角 `16-24px`，按钮和输入框圆角 `11-12px`。
- 动画保持 `150-300ms`，并支持 `prefers-reduced-motion`。

## 核心组件

- **步骤导航**：显示当前、已完成、未开放状态；移动端压缩为 8 个状态圆点。
- **主要操作**：每步最多一个高强调按钮，固定操作栏提供上一步和保存并继续。
- **字段校对**：保留可见标签，错误在字段下说明原因和处理方式。
- **依据摘要**：显示数据类别、匹配数量、快照版本和相似特征，不暴露敏感案例原文。
- **方案卡**：统一展示投入、收入、回本周期、ROI、依据和风险；使用 `aria-pressed` 表示暂选。
- **报告**：网页预览与 A4 打印共用结构，记录知识库、规则和模型版本。

## 禁止模式

- 不在完成数据确认前显示推荐方案。
- 不让浏览器或 AI 直接连接生产数据库。
- 不把技术提示词、模型参数或检索语句暴露给甲方。
- 不使用外部字体、图片、CDN、遥测或分析埋点。
- 不用颜色作为唯一状态提示，不使用 emoji 充当结构图标。

## 验收基线

- 375px、768px、1280px、1440px 无页面横向溢出。
- 移动端无需滚过完整导航列表即可开始录入。
- 所有触控目标至少 44px，键盘焦点清晰可见。
- 只有一个步骤面板可见，返回后保留项目和方案状态。
- 打印输出不包含应用导航与操作控件。
