# 文旅存量建筑再生投前模拟决策驾驶舱设计稿

日期：2026-06-11  
状态：已完成需求澄清与方向确认  
适用对象：福州创新创业大赛路演、集团内部立项、G/B 端客户方案沟通

## 1. 项目定位

项目建议名：**城更智算舱｜文旅存量建筑再生投前模拟决策系统**

一句话定位：

> 面向 G/B 端客户的 Web 版文旅存量建筑再生投前模拟决策驾驶舱，在投资前用数据、AI、工程造价和可视化回答：这栋楼、这片街区值不值得改，适合改成什么，要投多少钱，多久回本，文化与运营风险在哪里。

本项目聚焦城市存量闲置建筑、古建、历史街区低效空间的更新与再生规划。它不是单纯的设计软件，也不是静态可研报告，而是一个可在浏览器中运行的投前决策产品。客户在 Web 驾驶舱中完成项目录入、数据补全、方案生成、工程造价测算、投资回报测算、视觉生成和方案比选，最终导出客户成果包。

## 2. 双层叙事

### 路演故事层

以福州真实历史文化片区、古厝、老街铺面、旧院落或低效商业空间为故事入口，讲清楚城市更新、古建活化、文化保护和商业经营之间的矛盾。

路演表达重点：

- 过去：靠经验判断，先建后试，投资风险高。
- 现在：用 Web 驾驶舱在投资前模拟方案、成本、收益和风险。
- 未来：形成可复制的城市存量文旅资产更新平台。

### 产品交付层

产品形态是通用 Web 平台，不绑定单一片区。未来可复制到历史街区、古建院落、旧厂房、闲置楼宇、景区配套空间和城市公共文化空间。

## 3. 目标客户与应用场景

### 目标客户

- G 端：文旅局、国资平台、城投平台、历史文化街区管理方、城市更新主管单位。
- B 端：景区运营商、商业管理公司、文旅开发商、设计院、招商运营公司。

### 典型场景

- 历史街区低效空间更新。
- 古建院落活化。
- 老厂房或旧楼宇文旅改造。
- 景区配套商业提升。
- 城市公共文化空间再运营。

## 4. 核心痛点

1. 传统更新项目先建后试，投资决策依赖经验，缺少投前模拟工具。
2. 古建和历史片区商业化容易同质化，文化保护和收益目标存在冲突。
3. 设计、施工、运营割裂，前期方案缺少可回测的经营逻辑。
4. G/B 端客户缺少可视化、可量化、可汇报的投前辅助工具。
5. AI 生成效果图常常脱离工程、材料和造价，客户看得见效果但看不清成本。

## 5. 产品总体流程

完整业务链路：

1. 项目输入与数据补全。
2. 空间价值诊断。
3. AI 业态方案生成。
4. 规划工程与材料造价预评估。
5. 投资测算与风险评估。
6. 视觉方案与报告输出。

核心逻辑：

> AI 负责打开可能性，规则负责约束真实性，数据负责提高可信度，工程造价负责落地判断，人负责最终决策。

## 6. Web 产品形态

前端交付形态为 **Web 版投前模拟决策驾驶舱**。它是产品本体，不是展示附件。

### 运行优势

- Windows 和 macOS 均可使用，只需浏览器。
- 适合路演现场直接演示。
- 适合客户会议中进行交互式方案比选。
- 后续可继续接入 AI、地图、数据、报告导出、图像生成和视频生成能力。
- 短期适合通过低代码、vibecoding 或单页 HTML 原型快速实现。

### 首版布局

- 顶部：项目名称、当前案例、操作入口。
- 左侧：项目输入参数与数据源。
- 中间：地图、建筑卡片、空间价值诊断。
- 右侧：AI 方案卡、工程造价、财务结果。
- 底部：视觉方案、风险提示、报告导出。

## 7. 功能模块设计

### 7.1 项目输入与数据补全

用户选择或录入存量建筑、古建或历史片区信息：

- 片区名称。
- 建筑类型：古厝、闲置楼宇、旧厂房、老街铺面。
- 建筑面积。
- 空置率。
- 保护等级。
- 当前业态。
- 预算上限。
- 目标回本周期。
- 目标客群。
- 现状照片或现状描述。

系统展示数据补全卡片：

- 自有经营数据：历史活动客流、客单价、转化率。
- 公开数据：交通站点、人口、政策、文保约束。
- 商业数据：周边 POI、竞品业态、消费评价。
- 样例推演：模型假设、行业均值。

每条数据标注来源类型：真实、公开、合作、推演，并标注更新时间和可信度。

### 7.2 空间价值诊断

输出建筑或片区的基础判断：

- 区位潜力。
- 文化适配度。
- 改造难度。
- 商业承载力。
- 夜间运营潜力。
- 投资谨慎指数。

示例结论：

> 建议采用低干预修缮、复合轻商业、周末活动运营模式，避免重餐饮和高噪声夜间项目。

### 7.3 AI 业态方案生成

AI 生成 2-3 套候选方案：

- 稳健保守型。
- 活化增长型。
- 地标引爆型。

每张方案卡展示：

- 业态组合。
- 空间占比。
- 目标客群。
- 预计投入。
- 年收入预测。
- 回本周期。
- 主要风险。
- 推荐指数。

AI 用于生成方案、提炼资料、生成视觉提示词。最终结论必须经过规则、财务和工程造价模块校验。

### 7.4 规划工程与材料造价预评估

该模块是集团建筑规划、施工工程与前期测算能力的核心体现，放在 AI 方案生成之后、投资测算之前。

#### 规划与工程可行性

判断方案能不能落地：

- 建筑用途适配。
- 消防疏散条件。
- 动线组织难度。
- 外立面和风貌管控。
- 文保修缮限制。
- 夜间经营边界。
- 对周边居民影响。
- 审批报备难度。

#### 工期与工程量粗算

判断方案多久能开业：

- 轻改造：约 1-2 个月。
- 中度修缮：约 3-6 个月。
- 重度更新：约 6-12 个月。

工期拆分：

- 勘测。
- 方案设计。
- 审批报备。
- 施工改造。
- 招商进场。
- 试运营。

#### 材料与造价估算

当系统推荐业态方案和视觉效果图时，同步生成材料策略和造价区间。

材料与造价分类：

- 保留修缮类：木构件修缮、砖墙修补、瓦面修复、石材地面清洗。
- 基础工程类：结构加固、消防、机电、给排水、排烟、照明。
- 空间装修类：地面、墙面、吊顶、门窗、栏杆、软装家具。
- 景观院落类：铺装、绿植、水景、庭院灯、户外座椅。
- 数字文旅类：投影、AR 导览、互动屏、音响、传感设备。
- 展陈内容类：非遗展陈、导视系统、文创陈列、活动装置。

每一类展示：

- 面积或数量估算。
- 单价区间。
- 小计区间。
- 推荐材料。
- 可替代材料。
- 风险备注。

示例：

> 院落铺装：约 180 平方米 × 280-450 元/平方米 = 5.0-8.1 万元。建议材料为仿古青砖、防滑石材；替代方案为透水砖，成本可降低约 20%-30%。

计算逻辑：

> 工程造价 = 数量 × 单价区间 × 修缮难度系数 × 文保约束系数 × 预备费系数。

V0 可使用小型造价参数库，包含材料类别、典型单价区间、适用场景、风险系数和预算档位。

### 7.5 投资测算与风险评估

展示投前核心财务指标：

- 总投资。
- 年营收。
- 年净现金流。
- 回本周期。
- 3-5 年 ROI。
- 客流热力时段。
- 收入结构：租金、餐饮分成、活动票务、文创零售、研学团客。

基础公式：

- 客流预测 = 基础客流 × 交通系数 × 业态吸引系数 × 活动系数。
- 营收预测 = 客流 × 转化率 × 客单价 + 租金/招商/活动收入。
- 成本预测 = 建筑面积 × 改造单价 + 修缮系数 + 内容/设备/运营前置成本。
- 回本周期 = 总投资 / 年净现金流。
- 风险评分 = 文化冲突、施工复杂度、招商同质化、审批风险、运营扰民等加权评分。

风险分类：

- 文保与审批风险。
- 施工风险。
- 招商风险。
- 运营风险。
- 舆情风险。
- 数据置信度风险。

### 7.6 视觉方案与智能交付中心

视觉生成模块不自研底层模型，系统生成标准化 prompt 和分镜脚本，再通过外部国产图像或视频模型生成概念效果图。

建议链路：

> HTML 页面 → 轻量后端或 Serverless 代理 → 国产图像模型 API → 返回图片 URL → 驾驶舱展示效果图。

浏览器端不直接暴露 API Key。

视觉输出内容：

- 改造前上传图或预置示例图。
- AI 概念效果图。
- 改造前后对比图。
- 夜间运营氛围图。
- 空间材料说明。
- 视频分镜脚本。

固定提示：

> AI 视觉结果仅用于投前沟通与方案比选，不作为施工图、报批图或最终设计成果。

## 8. AI 与外部数据接入

### AI 接入

AI 能力分为三类：

1. 方案生成：根据输入条件生成业态组合与更新策略。
2. 资料解读：总结政策、竞品、客群评论和片区特征。
3. 视觉提示词生成：为效果图和视频生成 prompt 与分镜脚本。

AI 输出之后进入规则校验：

- 文保等级高：限制重餐饮和重装置。
- 预算低：推荐低干预运营型方案。
- 交通弱：降低夜间高客流预期。
- 同类业态过密：降低招商健康分。
- 结构条件弱：限制重设备和高荷载业态。

### 外部数据接入

V0 不做全自动爬取，采用数据包导入、手动刷新按钮和来源标签。后续逐步接入真实数据 API。

数据来源类型：

- 公开权威数据：政策文件、文保名录、城市规划、统计年鉴、公开交通站点。
- 半公开商业数据：POI、地图热度、点评、OTA、公开社交平台信息。
- 自有或合作数据：本地景区经营数据、活动客流、商业联动资源、研学渠道、招商资源。
- 样例推演数据：用于补足演示缺口，必须显式标注。

## 9. 国产图像/视频模型接入策略

首版建议优先接入图像生成，不急于接入视频生成。视频生成更慢、更贵，失败率更高，可先输出视频分镜脚本和预生成示例短片。

可考虑的模型方向：

- 阿里云百炼 / 通义万相：图像生成、图像编辑、图生视频能力较完整。
- 火山引擎方舟 / Seedream：适合接入豆包生态的图片生成能力。
- 腾讯混元生图：适合腾讯云生态和中文场景。
- 百度千帆 / AI Studio：适合作为文心生态备选。

接口原则：

- API Key 存放在服务端或 Serverless，不写入前端。
- 生成任务采用异步状态轮询。
- 生成结果保存为 URL，并进入客户成果包。
- 所有图片标注为概念级投前沟通材料。

## 10. 智能交付中心与客户成果包

客户最终拿到的不是网页截图，而是由 Web 驾驶舱自动生成的综合型成果包。

成果包名称：**存量建筑再生投前决策报告包**

### 成果包内容

1. 投前可行性报告：项目背景、空间现状、数据依据、市场机会、更新必要性、推荐结论。
2. 三案比选报告：稳健保守型、活化增长型、地标引爆型，对比业态组合、投入、收益、工期和风险。
3. 规划工程与材料造价预评估：规划适配、修缮难度、工程量粗算、材料策略、造价区间、替代材料建议。
4. 投资测算表：CAPEX、年营收、年净现金流、回本周期、3-5 年 ROI、敏感性分析。
5. 风险诊断书：文保审批、施工、招商、运营、舆情、数据置信度风险及应对建议。
6. AI 视觉方案册：改造前后对比图、概念效果图、夜间运营氛围图、空间材料说明、视频分镜脚本。

### 输出格式

V0 支持：

- 网页内预览报告。
- 导出 HTML 报告。
- 导出 Markdown 方案文本。
- PDF 报告可通过浏览器打印或后续接导出服务实现。
- 效果图区域先用预生成示例图，后续接图像模型 API。

## 11. 商业模式

### 短期

- 项目制咨询报告。
- 单项目投前诊断收费。
- 历史街区或古建活化专项方案收费。

### 中期

- SaaS 工具订阅。
- 数据报告收费。
- 方案比选和工程造价预评估增值服务。
- AI 概念图生成按次收费。

### 长期

- 城市级文旅资产更新平台。
- 运营分成。
- 数据服务。
- 与设计、施工、招商、运营形成闭环合作。

## 12. 竞争差异

对标奥创引擎等案例，本项目不主张简单复制 AIGC 空间设计平台，而强调投前商业模拟和真实落地能力。

核心差异：

- 奥创引擎偏空间设计、城市更新和 AIGC 工具链。
- 本项目强调投前商业模拟、真实运营数据、国企资源整合、工程造价预评估和本地文旅落地。
- 核心不是只画图，而是判断该不该投、怎么投、怎么建、多少钱、多久开业、投后能不能活。

## 13. 落地路径

### V0：比赛与内部验证

- Web 单页驾驶舱原型。
- 样例数据包。
- 小型造价参数库。
- 规则化测算模型。
- 预生成视觉效果图。
- 网页内报告预览与 Markdown/HTML 输出。

### V1：内部试用工具

- 接入真实片区数据。
- 接入 POI、政策、经营数据。
- 支持客户项目库。
- 支持方案参数调整和导出。
- 接入 LLM API 做方案生成和报告草稿。

### V2：对外交付平台

- 接入地图数据、图像生成模型、视频生成模型。
- 建立文旅项目案例库、材料造价库和运营指标库。
- 支持多客户、多项目、多城市复用。
- 形成 SaaS、项目制和数据服务结合的商业化产品。

## 14. 风险与应对

- 数据真实性不足：标注来源、更新时间、可信度，保留人工审核。
- AI 输出不可控：用规则校验、财务测算和人工确认约束。
- 文保合规风险：将文保约束前置，不将概念图作为报批依据。
- 商业预测偏差：采用区间预测、情景模拟和敏感性分析。
- 工程造价误差：明确为投前粗算，不替代正式工程量清单和施工图预算。
- 技术能力不足：先做轻量 Web 原型，后续逐步接真实 API。
- 成本与接口风险：图像/视频模型采用可插拔接口，控制调用次数和费用。

5. 给出 V0-V2 落地路径，证明短期能做、长期可扩展。
