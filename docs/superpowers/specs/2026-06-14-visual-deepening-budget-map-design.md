# 视觉深化与工程投入可视化设计

## 1. 目标

将第七步“视觉深化”从占位图形升级为甲方可直观理解的方案沟通页：既能通过同机位前后对比感受改造效果，也能将已选方案的工程造价映射到庭院中的具体构件，说清“钱用在哪里”。

首套演示以福州三坊七巷文儒坊 16 号院“中华唐梦”为文化背景，选用“复合活化型”表达方向。它是概念级示范，不宣称还原现场。

## 2. 成果边界

- 页面明确标注“AI 概念模拟，非现场实拍”。
- 视觉内容不作为施工图、报批图、文保修缮方案或最终投资承诺。
- 公开资料仅用于确认项目的文化定位和空间语汇，不直接将第三方图片放入产品。
- 新生成的图片使用虚构同机位院落，避免让用户误以为是文儒坊 16 号院的真实改造前后照。

## 3. 视觉资产

生成四张 16:9 横向图片，保持严格相同的镜头位置、构图、透视和主要建筑轮廓：

1. 日间现状模拟。
2. 日间复合活化效果。
3. 夜间现状模拟。
4. 夜间复合活化效果。

空间基底包含福州古厝常见的白墙黛瓦、深檐木构、条石铺地、天井和院落层次。改造后加入可逆的唐风织物、小型文化展陈、茶歇家具、低位绿化、檐下照明和小规模演艺节点，不做永久性仿唐建筑加建。

## 4. 页面信息架构

### 4.1 顶部摘要

- 展示已选方案名称、一句话摘要和当前总投资区间。
- 展示“AI 概念模拟”和成果边界标识。
- 数据始终跟随第六步已确认方案，不在第七步提供另一套方案选择器。

### 4.2 同机位前后对比

- 主区域是大幅 before/after 对比组件。
- 分割线可用鼠标、触控和键盘左右方向键调整。
- 分割线初始为 50%，两侧固定标识“现状模拟”和“方案效果”。
- 切换日间和夜间时保留当前分割位置，避免视觉跳动。
- 图片未加载成功时显示简短错误文案，不显示空白画布。

### 4.3 三个标签页

- `日间`：日间现状与改造后对比，重点看材料、院落尺度和使用场景。
- `夜间`：夜间现状与改造后对比，重点看低照度灯光、活动氛围和邻里影响边界。
- `材料说明`：改造后图上预算热点、工程详情卡和资金分配条。

标签使用标准 `tablist / tab / tabpanel` 语义，支持键盘切换并保持可见焦点。

## 5. 材料与预算映射

### 5.1 图上热点

材料页默认在日间改造效果图上标出 6 个编号热点：

1. 勘测、结构初检与现场数据。
2. 木构、墙面与基础修缮。
3. 消防、弱电、给排水与隐蔽机电。
4. 条石铺地、院落景观与低位绿化。
5. 檐下照明、庭院灯与夜间运营节点。
6. 唐风可逆展陈、家具、织物和导视。

点击或键盘激活热点后，对应构件使用半透明墨绿轮廓强调，右侧详情卡同步更新：

- 本类目金额和总投资占比。
- 主要材料与工程内容。
- 低干预或可逆的实施原则。
- 造价依据和人工复核提示。

### 5.2 资金分配条

- 详情图下方显示横向堆叠条，每个分段与热点使用相同颜色和编号。
- 分段显示类目名、金额和占比；空间不足时，图内仅显示百分比，完整名称放在下方图例。
- 鼠标悬停、点击或键盘聚焦分配条时，与图上热点双向联动。
- 颜色不作为唯一识别方式，同时使用编号、文字和选中轮廓。

## 6. 数据逻辑

- 视觉页仅读取现有的 `selectedPlanId`、项目数据、造价条目和方案乘数。
- 每个预算热点与一个或多个现有造价类目建立显式映射，不在视觉页硬编码独立金额。
- 热点金额由当前方案的工程造价结果汇总；占比由“类目金额 / 全部可视化类目金额”计算。
- 返回第六步更换并确认方案后，第七步的标题、总投资、热点金额、占比和分配条全部重算。
- 若某类造价数据缺失，对应热点显示“待补充”，不生成虚构金额；其他类目仍可正常展示。
- 资金分配条的百分比总和必须等于 100%，显示层的四舍五入尾差由最后一项吸收。

## 7. 视觉与响应式规则

- 延续当前墨绿、暖白和铜金点缀，标题使用现有思源宋体语言。
- 大屏上，材料页为左侧图像、右侧详情卡；分配条横跨整个容器。
- 小屏上，图像、详情卡和分配条依次单列排列；热点点击区不小于 44 x 44 像素。
- 动画时长控制在 150–300 毫秒，并尊重 `prefers-reduced-motion`。
- 图片预留固定宽高比，避免加载导致布局跳动。

## 8. 测试与验收

- 日间和夜间切换使用正确的前后图，并保留分割位置。
- 分割线支持鼠标、触控和键盘，且不能超出 0–100% 范围。
- 标签页具有正确语义、焦点顺序和选中状态。
- 选中图上热点、分配条或图例中任一入口，其他两处必须同步高亮。
- 热点金额与当前方案工程造价结果一致，不出现第二套独立数值。
- 切换已确认方案后，所有金额和占比自动更新，且百分比总和为 100%。
- 缺失造价数据时明确降级为“待补充”，不生成无依据数值。
- 在主流桌面宽度和手机宽度下不出现水平滚动、图片拉伸或重要文字遮挡。
- 现有造价、投资测算、方案选择和报告结果不得因本页改造而发生回归。
